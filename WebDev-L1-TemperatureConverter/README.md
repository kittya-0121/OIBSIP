
## Project 3: Temperature Converter

This project is a responsive Temperature Converter web application developed as part of my Web Development Internship at Oasis Infobyte (OIBSIP).

## Project Description

The Temperature Converter allows users to enter a temperature value and convert it between different temperature units. JavaScript is used to perform the conversion and display the result.

## Features

* Convert Celsius to Fahrenheit
* Convert Fahrenheit to Celsius
* Simple and user-friendly interface
* Input temperature value
* Unit selection
* Instant conversion
* Responsive design
* Clear and easy-to-use layout

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run

1. Download or clone the project.
2. Open the `WebDev-L1-TemperatureConverter` folder.
3. Open `index.html` in a web browser.
4. Enter a temperature value.
5. Select the required temperature unit.
6. View the converted temperature.
