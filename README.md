# Web Development Internship Projects

This repository contains the web development projects completed as part of my **Web Development Internship**.

The projects were developed using **HTML, CSS, and JavaScript** to practice frontend development, responsive design, user interaction, and website development.

## Projects

### 1. Saiguru Industries - Business Website

A responsive website created for **Saiguru Industries**, a fabrication business.

The website focuses on providing information about the company, its services, and contact details through a simple and professional interface.

**Features:**

* Home section
* About section
* Services section
* Contact section
* Responsive layout
* Navigation menu
* Professional UI
* Business information

**Technologies:**

* HTML5
* CSS3

---

### 2. Personal Portfolio

A personal portfolio website created to showcase my profile, skills, projects, education, interests and contact information.

**Features:**

* Personal introduction
* About Me section
* Skills and technologies
* Projects showcase
* Education
* Areas of Interest
* Profile photo
* Contact section
* GitHub, LinkedIn and Email links
* Responsive design
* Smooth navigation

**Technologies:**

* HTML5
* CSS3
* JavaScript

---

### 3. Temperature Converter

A responsive temperature conversion tool that allows users to convert temperatures between **Celsius, Fahrenheit and Kelvin**.

**Features:**

* Celsius conversion
* Fahrenheit conversion
* Kelvin conversion
* Input validation
* Temperature conversion
* Displays converted values
* Responsive design
* Simple and interactive interface

**Technologies:**

* HTML5
* CSS3
* JavaScript
