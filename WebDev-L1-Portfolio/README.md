## Project 2: Personal Portfolio

This project is a responsive personal portfolio website developed as part of my Web Development Internship at Oasis Infobyte (OIBSIP).

## Project Description

The Personal Portfolio is designed to showcase my profile, education, technical skills, projects, and contact information. The website provides a simple and professional way to present my work and web development skills.

## Features

* Responsive navigation bar
* Home section
* About section
* Skills section
* Projects section
* Contact section
* Profile photo section
* LinkedIn link
* GitHub link
* Email link
* Responsive design for mobile and desktop
* Interactive features using JavaScript

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
WebDev-L1-Portfolio/
│
```

## How to Run

1. Download or clone the project.
2. Open the `WebDev-L1-Portfolio` folder.
3. Open `index.html` in a web browser.
4. Navigate through the different sections of the portfolio.
